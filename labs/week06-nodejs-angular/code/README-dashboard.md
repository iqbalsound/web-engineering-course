# Angular dashboard overlay

The Angular project is generated by the CLI so that it matches your installed version:

```bash
npx --yes @angular/cli@latest new dashboard --defaults --skip-git
```

Then copy `src/app/app.ts`, `src/app/app.html` and `src/app/app.config.ts` from this folder over the generated files
(keep any router provider your CLI version generated in `app.config.ts`).
