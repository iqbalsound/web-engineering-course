# Course file records

The course index requires the best, worst and average student script for each item. Record the roll number and mark of each script that you place in the file.

| Mid-Term Subjective | 10 |  |  |  |  |
| OHT | 10 |  |  |  |  |

Marks available per CLO come from the OBE assessment mechanism: CLO_1 = 28, CLO_2 = 35, CLO_3 = 37. A student attains a CLO when their share of marks for that CLO is at least the department threshold (commonly 50–60%). Attainment = students attaining ÷ students assessed.

| CLO | Items and marks | Max | Threshold (marks) | Students ≥ threshold | Students assessed | Attainment % |
| --- | --- | --- | --- | --- | --- | --- |
| CLO_1 | A1 4 + Q1 4 + Mid objective 10 + Final subjective 10 | 28 |  |  |  |  |
| CLO_2 | Mid subjective 10 + OHT 10 + Final objective 15 | 35 |  |  |  |  |
| CLO_3 | A3 6 + Q3 6 + Final subjective 25 | 37 |  |  |  |  |

Formative items (A2 and Q2) are excluded from attainment because the OBE sheet gives them zero marks, but their results are useful for early intervention.
