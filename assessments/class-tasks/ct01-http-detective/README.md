# CT-1 (Week 1, 20 min, pairs, CLO_1): HTTP Detective

Run `curl -sI` against three sites (for example `hamdard.edu.pk`, `example.com` and `webeng.test`). Build a table with URL, status, `Server`, `Content-Type`, HTTP version and cache-related headers. Decide from the headers whether each site probably uses a proxy or CDN.

**Deliverable:** filled table and two written observations.
