## Rules for Students

- At least **75% attendance** is required. Phones are on silent. Late arrivals are not admitted to class.
- There are **no individual make-up exams** and no exams to improve grades (course outline).
- **Academic honesty:** cheating and plagiarism are serious offences. Any copied code, text or diagram must be acknowledged. You may discuss ideas, but write and run your own solution. Disciplinary action is recorded in student records.
- Submissions are PDF (reports) or a Git repository link (code). File and folder names use your roll number, for example `24-001-A1.pdf`.
- Every program must run on **your own** operating system (Rocky Linux 10 or Kubuntu 26.04). State which one in your README.
